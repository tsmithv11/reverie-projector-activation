Used in the operator sidebar and copied to `dist/brand` for offline use.

## Audience surround and shape border

The supplied Reverie palette is recorded in `app/core/composition.js`: First Light `#FDCADB`, Reverie Pink `#FAA0D0`, Soft Orchid `#E1A3D7`, Reverie Lilac `#C49ED8`, Horizon Blue `#7A9DDA`, Deep Reverie `#24152F`, Blush Horizon `#F7B7DB`, and Dawn Violet `#A8AEDB`.

The surround and transition gradient run from First Light through Reverie Pink, Soft Orchid and Reverie Lilac to Horizon Blue. Camera and bay surrounds use the same colors as transparent washes over the existing imagery. The opaque shape border blends Reverie Pink, Soft Orchid and Reverie Lilac. The audience background in `app/style.css` uses the same five gradient stops for display margins; keep it aligned with the canvas palette.

Words in motion uses Horizon Blue for resting “Reverie 2026” text, smoothly blending through Reverie Lilac and Reverie Pink to First Light as movement increases, against a solid Deep Reverie background. Its operator thumbnail uses the same blue, pink and deep colors. Other scene artwork retains its own colors.
